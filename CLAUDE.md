# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

**Flyte: A Disc Golf Course Builder and Manager** — tycoon/management game in Godot 4.6.2.  
Players build isometric disc golf courses, manage business economics (income, expenses, upgrades), design holes with quality ratings, and observe NPC player traffic generating revenue.

**Current phase:** Phase 3 — story campaign playable. `StoryManager` advances chapters 0–6 strictly in order, queues beats one at a time through `DialogueOverlay` (letter / newspaper / card / dialogue styles, cosmetic choices), pauses the world while a beat is open, and migrates pre-story saves. All dialogue from `STORY.md` is in `StoryManager.BEATS`. New games start on Uncle Ray's land (3 rough ~2★ holes); player name prompt after his letter, then a camera pan over his holes (`pan` beat style). Every `STORY.md` beat and recurring element is in: Ch3 tournament toast series, playable Ch4 **away rounds**, Diana's Ch5 sponsor, ambient-only final card, Dani's Ch6 epilogue, Ray's disc bag on the home gate, the shed toast. Flat-vector portraits for every on-screen speaker (player — male or female look, chosen at the name prompt — Jess, Marcus, Diana, the Regular) generated by `tools/gen_portraits.py`, shown at 112px. Phase 2 (multi-course empire, 6 real-life courses, affiliate tiers) is complete.  
**Long-term:** full world map with 6+ real-life courses, narrative campaign, Steam + mobile release.  
See `GOALS.md` for the full phased roadmap.

**Released:** v1.0 is public and free (MIT) at https://github.com/ktraab/flyte since 2026-11-22 — Windows/macOS/Linux zips on the Releases page. This repo stays the private working repo; see DEVLOG "Released" for how to ship an update (fresh-history copy, GitHub noreply author, rebuild zips, `gh release create`).  
Targets (later): Steam (Windows + Mac), iOS App Store, Google Play. Cross-platform cloud save sync.  
All source lives in `flyte--a-disc-golf-course-builder-and-manager/`.

## Running

Open Godot 4.6.2, import `flyte--a-disc-golf-course-builder-and-manager/project.godot`, press **F5**.

CLI headless:
```
godot --path flyte--a-disc-golf-course-builder-and-manager --headless
```

## Testing

```
flyte--a-disc-golf-course-builder-and-manager/tools/run_tests.sh          # all suites
flyte--a-disc-golf-course-builder-and-manager/tools/run_tests.sh story    # tests whose name contains "story"
```
- Filter matches `suite::name` (e.g. `run_tests.sh hole_score`). Redirect output to a file — the watchdog's `sleep` otherwise keeps the terminal attached for 5 minutes.
- Headless smoke tests in `tests/test_*.gd` (extend `res://tests/TestCase.gd`; methods named `test_*`; optional `before_each`). Register new suites in `tests/run_tests.gd` → `SUITES`.
- The wrapper sets `HOME` to a temp dir so `user://` saves are isolated — **never run `tests/run_tests.gd` directly** (it aborts if the user dir isn't isolated).
- Exit code is non-zero on any failed check **or any SCRIPT ERROR / ERROR in the log** (GodotSteam load noise is filtered).
- Helpers: `goto_state()`, `quiet_story()` (marks all beats seen so dialogue can't pop up), `drain_dialogue()`, `press_key("ui_cancel")`, `advance_economy(seconds)`.
- Run the suite after every change; add a test with every bug fix.

### Key systems

**GameWorld3D** (`scenes/game_world/GameWorld3D.gd`, `class_name GameWorld3D`)
- 150×150 isometric tile grid, CELL_SIZE=2.0, 300×300m world, accessed via `GameManager.world`
- `TileType` enum: GRASS=0, FAIRWAY=1, PATH=2, WATER=3, ROUGH=4, TREE=5, TEE=6, BASKET=7, ENTRANCE=8, PARKING=9, RESTROOM=10, FOOD_STAND=11, PRO_SHOP=12, SAND=13, ROCK=14 (tool only), OB=15 (tool only), **BENCH=20, FLOWER_BED=21, SCULPTURE=22** (decorative — count toward happiness and the course amenity bonus; global 20-piece happiness cap)
- **OB and ROCK are overlay layers** — not stored in `_tiles`. Stored in `_ob_zones` (per-hole) and `_rock_overlays`. Never check tile type for OB/Rock; use `world.is_ob_at(pos, hole_idx)` and `world.is_rock_at(pos)`
- Tree size variants: 0=small(0.55×), 1=medium(1.0×), 2=tall(1.45×) — default is 2 (tall)
- Undo stack: `world.undo_paint()` — ⌘Z/Ctrl+Z in CourseBuilder. Entries are **groups** (one per mouse stroke / move / erase; `begin_undo_group()`/`end_undo_group()` for scripted edits); cleared when a layout is replaced
- **Builder painting rules:** ground tiles (`GROUND_TILES`) never replace objects; objects never replace a different object — only `TOOL_ERASE` (19) / Delete removes them. `SINGLE_PLACE_TOOLS` place once per click. Placing a hole's tee/basket again moves it. Tees auto-face their basket / first waypoint (`tee_facing_for`, `_aim_tee_at_basket`). Select: `move_object(src, dst)` (ground targets only, keeps terrain height). Route edit: `insert_route_waypoint` (best-fit position), `move_route_waypoint`, `remove_route_waypoint`. CourseBuilder `_apply_world_tool_mode()` is the only place that switches the world between select and paint modes (Select = id 18, never painted)
- NPC walking LOS (`_los_clear`) is a supercover traversal over the BFS walk grid — no corner cutting across water
- Staff spawned here from `_on_staff_hired` / removed from `_on_staff_fired`
- Key API: `get_tiles_of_type(tile_type)`, `is_ob_at(pos, hole_idx_0based)`, `is_rock_at(pos)`, `get_ground_y(pos)`, `get_tree_fly_height(pos)`, `has_facility_near(pos, tile_type, radius)`, `get_holes_info()`, `get_course_rating()`, `get_course_happiness()`, `find_walkable_path(from, to)`, `spawn_score_popup(pos, text, color)`, `export_full_state() → Dictionary`, `import_full_state(state)`, `clear_all_tiles()`, `load_terrain_preset(tile_map)`, `get_per_hole_breakdown() → Array`, `get_happiness_breakdown() → Dictionary`, `get_rating_breakdown() → Dictionary`

**HoleScore** (`core/simulation/HoleScore.gd`) — the only hole-design scorer (spec `docs/superpowers/specs/2026-11-21-hole-scoring-design.md`). `score(hole, world)` → `{stars, parts{length,fairway,challenge,framing,shape}, penalty, length_m, par, ideal, tips}`. Stars reward design for par (bands par3 45–100 m, par4 100–170, par5 170–240); fairway/framing scale with hole length; challenge needs two hazard types for full marks (water, sand, OB, rocks, or **woods** = trees within 2 cells of the line; trees 3–5 cells out count as framing); straight holes cap at 4.5★ (shape 0.5), angled 4.75★, dogleg/elevation 5★; fairness penalty for an unreachable or boxed-in basket. `course_bonus()` adds ≤0.3★ (variety + amenities, 6+ holes). Used by `get_hole_rating` (memoised; layout key also hashes waypoints/OB/rocks), `get_per_hole_breakdown`, `get_rating_breakdown`, `HoleCritique` (score = stars × 20) and the Analytics panel. Par auto-suggested from length when a tee/basket is placed (`GameWorld3D._auto_par`); Hole Manager can override. 5★ goal = 4.8.

**PropFactory** (`scenes/game_world/PropFactory.gd`) — static builders for every prop (trees, basket, tee pad, facilities, decor, hazards). GameWorld3D calls `Props.make_*()`; pass world state in (e.g. `make_basket(_flag_nodes)`, `make_tee_pad(orient, color)`). `PropFactory.CELL_SIZE` must equal `GameWorld3D.CELL_SIZE` (tested).

**PropBatch** (`scenes/game_world/PropBatch.gd`) — instanced props. **Trees, rough grass and sand are not scene nodes**: GameWorld3D `_batch_cell()` feeds per-cell instance lists into MultiMeshes — one per *part* per 50×50-cell chunk (fixed `custom_aabb`, so the engine skips off-screen chunks and chunks outside the shadow range; nothing visible is culled). **Tree detail:** `gfx_trees` (preset key `trees`; Low = 0, Medium/High = 1; Custom → Tree Detail row). On 0, `GameWorld3D._set_tree_detail(false)` swaps each tree part's mesh via `PropBatch.set_part_mesh()` for `Props.reduced_tree_mesh()` (ImporterMesh.generate_lods, most detailed LOD ≤ 35 % of the triangles; built lazily once, ~0.1 s; leaf-card surfaces that can't simplify stay full). Instances never move (each tree-model surface split out so bark/leaves tint separately; one blade part; one grain part). Swap-remove slots → painting is O(cell). Don't look for tree nodes in `_props`; use `world.get_tree_positions_in(lo, hi)` / `world.set_tree_hidden(cell, on)` (PlayTestController occlusion fade) and `get_prop_batch_stats()`. Node trees are still built by `_pick_tree()` for the build-mode hover preview (and as a fallback if no FBX models load). Instance colours use `Props.instance_mat()` (sRGB vertex colour).

**Layout cache** (GameWorld3D `_layout()`) — `get_holes_info()`, `get_hole_rating()`, `get_course_rating()`, `get_course_happiness()`, `get_facility_counts()`, `_count_decor_tiles()`, `get_tiles_of_type()` are memoised per layout. Key = `hash()` of `_tiles`/`_tile_hole_num`/`_tile_par`/`_tile_heights` (C++, ~0.15 ms), so edits anywhere invalidate automatically — no dirty flags to remember. Results are returned as copies. If you add a stat that reads another dictionary, add that dictionary to the key. Gameplay's minimap caches its terrain layer the same way.

**Graphics presets** (GameManager `_GFX_PRESETS`) — also carry `scale` (3D render scale via root `scaling_3d_scale`, bilinear; UI stays sharp) and `clutter` (grass tufts). Low = 75% scale, no shadows, no tufts, simplified trees, 30 FPS. First launch with no saved preset uses `recommended_graphics_preset()` (Low on mobile / integrated non-Apple GPUs / software renderers, else Medium). Settings → Graphics → Custom has Render Scale + Grass Tufts rows (built in code); sync uses `set_pressed_no_signal` so picking a preset doesn't flip to Custom. **Auto guard** (`gfx_auto`, default on, saved as `[graphics] auto`): GameManager `_process` samples FPS once a second in GAMEPLAY/COURSE_BUILDER (skipped headless / unfocused); if the median of 8 samples is under 70 % of `perf_target_fps()`, `lower_graphics_one_step()` steps High→Medium→Low, then glow/shadows/tufts off, simplified trees, 30 FPS cap, render scale 75→60→50 %, and toasts what changed. Never raises settings. Samples reset on state change / settings change. Settings → Graphics has an always-visible Auto Adjust switch (`_build_auto_row`). Tests feed fake samples via `perf_guard_sample(fps)`.

**Course persistence + certification** (GameManager) — every owned course keeps its build: snapshots are stamped `course_id` (`_tagged_snapshot`) and only restored into the matching course (`_has_valid_snapshot`); untagged non-home data is ignored. `get_course_stats(id)` (live for active, recorded otherwise, persisted in `[courses] stats`), `is_course_certified(id)` (≥9 holes, ≥3.5★, ≥1 restroom — once earned it is remembered in `_certified`, saved as `[courses] certified`, never revoked), `get_certified_circuit_count()`; emits `EventBus.course_certified(id)`.

**Default course** — `GameWorld3D._generate_default_course()` builds Uncle Ray's 3-hole loop (only used when there's no home snapshot). Helpers `_paint_rect()`, `_place_hole()`. Tests pin it at 1.5–3★.

**CourseBuilder modules** — `core/simulation/HoleCritique.gd` (pure `critique(hole_info)`), `scenes/ui/screens/course_builder/` (HoleManagerPanel, LayoutSlots, ArchitectOverlay); CourseBuilder keeps nodes + same-named delegates so `.tscn` signal hookups still resolve.

**Away rounds** (GameManager + `core/data/AwayLayouts.gd`) — World Map → *Play an Away Round* on any unlocked circuit course: `start_away_round(id)` snapshots the active course, loads the preset + front-nine tees/baskets (`GameWorld3D.load_away_course`), and Gameplay opens `PlayTestController` (`away_course_name` set). *Head Home* → `Gameplay.stop_play_test()` → `end_away_round(scores, pars)` restores the course and emits `EventBus.away_round_completed` (only if all 9 holes played). While `is_away_round()`: economy `_process/_tick` frozen, no NPC spawning, `_tagged_snapshot`/stats use the saved real course, and any state change other than GAMEPLAY/PAUSED abandons the round. Best score per course persisted in `[courses] away_best`.

**CourseUnlocks** (`core/data/CourseUnlocks.gd`) — `is_met(unlock_key)`; single source for World Circuit unlock conditions (WorldMap cards + StoryManager Ch4).

**NPCPlayer** (`scenes/gameplay/NPCPlayer.gd`)
- Spawned by GameWorld3D; walks entry path → plays each hole (throw arc + walk) → exits
- Needs system: hunger/thirst/bathroom drain; leaves early if maxed without facility nearby
- VIP flag: `_is_vip` — 3× green fee, gold dot, `vip_arrived`/`vip_left` signals
- `get_info() -> Dictionary` — used by click-inspect panel
- Area3D (collision layer 2) for click detection → emits `EventBus.npc_inspect_requested`
- Emits `EventBus.round_completed(npc_id, is_vip, earn, holes_played)` on finish

**DiscProjectile** (`scenes/gameplay/DiscProjectile.gd`) — scripted flight + ground physics (not rigid bodies)
- Before `launch()`: set `hole_num`, `_turn`/`_fade` (metres; negative = forehand), `basket_pos` (enables chain catches), `aim_compensate` (aim right so the fade ends on target — NPCs + aim-assisted player throws)
- Flight math is static and shared with the aim preview + tests: `flight_params()` (applies wind: headwind → more turn + lift, tailwind → more fade; low putts barely drift), `flight_point(p, t)`, `aim_point()` (throws at the basket finish at chain height)
- Shape: eased speed (fast → ~0.4×), asymmetric arc peaking t≈0.42, turn early / fade late, banks with the curve
- Hits (per frame, vs height above ground): chains (`in_basket = true`, segment closest-approach test) · rim/pole glance · trees (kick back/sideways, never rests in a tree cell) · rocks · rising ground (hills) · water (splash, +1, lie = last dry point)
- Touchdown → skip by tile (along the final flight direction, scaled by throw length) → roll downhill on slopes ≥10% → rest. **OB is judged at rest only** (+1, lie = last in-bounds point). Rest in rough/sand = +1 (user's call)
- Emits `EventBus.disc_impact(kind, pos)` → GameAudio plays `assets/audio/sfx/*.wav` (generated by `tools/gen_sfx.py`)
- Uses `world.is_ob_at(pos, hole_num)` and `world.is_rock_at(pos)` — NOT tile type constants
- Player throws: `PlayTestController._plan_throw()` (one source for the throw and the dotted flight preview); holing out requires a chain catch (old 2 m auto-catch removed)

**StaffMember** (`scenes/gameplay/StaffMember.gd`)
- Wandering visual for hired staff; snaps to terrain y each frame
- Type 0=Groundskeeper(green), 1=Disc Pro(blue), 2=Concessions(orange)
- Wanders to type-appropriate tiles via `world.get_tiles_of_type()`
- Area3D (layer 2) → click-inspect via `EventBus.npc_inspect_requested`

**EconomyManager** (`core/economy/EconomyManager.gd`)
- `earn(amount, source)`, `spend(amount, category)` — all balance changes go through here
- `earn()` calls `GoalsSystem.notify_balance()` automatically
- Staff: `hire_staff(type)`, `fire_staff(type)`, `get_staff_count(type)`
- Tournament: `can_start_tournament()`, `start_tournament()`
- Emits `EventBus.staff_fired` on fire (GameWorld3D listens to remove visual)
- `get_prestige_breakdown() → Dictionary` — 5 components (rating 35%, happiness 30%, facilities 20%, tournaments 10%, goals 5%)
- `get_net_income_rate() → float` — `income_rate - expense_rate`
- New games start with `EconomyManager.STARTING_BALANCE` = $10,000 (matches Ray's letter; Ray's 3 holes earn ~$300–600/day idle)
- Rates are **$ per real second** (`_tick` every 1s); one in-game day = 60s. Balance knobs are constants at the top (`STAFF_SALARY`, `DISC_PRO_BONUS_PER_TIER`, `CONCESSIONS_PER_STAFF`, `FOOD_STAND_INCOME/TIER_MULT`, `RATING_FEE_*`, `FEE_ELASTICITY`). UI text reads these constants — change numbers in one place
- Green fee: per-player fee × `(0.7 + 0.15 × rating)`; arrivals scale with `fee^-1.5` (`get_spawn_rate_mult`), so 1.2–1.5× is the sweet spot
- Membership dues are weekly, paid once per day in `_tick_membership()` (not in `income_rate`)
- `serialize() / deserialize()` — used by GameManager for per-course economy snapshots

**GoalsSystem** (`autoloads/GoalsSystem.gd`)
- `get_active_goal() -> Dictionary`, `get_all_goals() -> Array`, `get_current_value(type) -> float`
- Notify manually for holes/balance/rating: `notify_hole_count(n)`, `notify_balance(bal)`, `notify_rating(r)`

### Godot 4.6 Node-Ready Gotcha

`_ready()` fires before PackedScene children enter the tree. Use `call_deferred("_setup_nodes")` + `find_child(name, true, false)` pattern for all screen node lookups. `on_screen_entered()` is safe for first-run setup.

### physics_object_picking

`Area3D.input_event` requires `get_viewport().physics_object_picking = true`. Gameplay.gd enables this in `on_screen_entered` and disables in `on_screen_exited`.

### GDScript Conventions

- `snake_case` vars/functions, `PascalCase` class names/node names
- Signals over direct method calls for cross-system comms
- Autoloads loaded top-to-bottom; lower singleton cannot reference higher one
